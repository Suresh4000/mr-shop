# Phase 0: Setup and Decisions

**Estimate:** 1.5 working days  
**Dependency:** None  
**Status:** Gate met for this learning project 2026-10-28 (accounts not created; no live Supabase)
**Purpose:** Approve the business decisions and create accounts so later phases are not blocked.

## Tasks

| ID | Task | Deliverable |
|---|---|---|
| 0.1 | Confirm business decisions | Pending items in `../decision-log.md` resolved or given an owner and date |
| 0.2 | Create accounts | Domain, business email, GitHub, Supabase, hosting, email service |
| 0.3 | Plan content collection | List of products, photos, size charts, descriptions and prices with an owner and deadline |

## Decisions that must be approved

- Product range and approximate catalog size
- Size ranges and colour handling
- Delivery area and COD pincodes
- COD limits (see `../cod-business-rules.md`)
- Shipping charge rule
- Returns and exchange window
- GST handling and invoice needs (confirm with an accountant)
- Hosting plan with commercial-use terms
- Launch date and budget

## Acceptance criteria

- Every decision is Approved, or Pending with an owner and a follow-up date.
- Accounts exist and credentials are stored in a password manager, not in files.
- Content collection has a named owner and deadline.

**Gate:** Do not start Phase 2 until COD rules, delivery area, returns window and hosting are approved. Non-blocking details can stay open.

## Notes for AI assistants

Do no coding in this phase. If asked, help draft decision options and fill the decision log, but never mark a decision Approved yourself.
